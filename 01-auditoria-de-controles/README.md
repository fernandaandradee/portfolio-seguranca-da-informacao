Auditoria de Controles de Sistemas

Tipo: Projeto acadêmico — Auditoria Forense de Sistemas Digitais.

Objetivo

Analisar controles de acesso em um ambiente simulado, identificando possíveis falhas de segurança.

Atividades realizadas

Análise de contas e permissões de usuários.

Identificação de contas com privilégios elevados.

Verificação de informações em arquivos de auditoria.

Registro dos achados identificados.

Conhecimentos desenvolvidos

Linux, comandos Bash, auditoria de sistemas e análise de evidências.

Este projeto foi desenvolvido para fins educacionais.
