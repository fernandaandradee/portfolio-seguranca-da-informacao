Análise Forense de Dispositivo USB

Tipo: Projeto acadêmico — Auditoria Forense de Sistemas Digitais.

Objetivo

Praticar a preservação e a verificação da integridade de evidências digitais.

Atividades realizadas

Trabalho com imagens de disco.

Cálculo e comparação de hashes SHA-256.

Verificação da integridade das cópias.

Registro dos resultados da análise.

Conhecimentos desenvolvidos

Análise forense digital, integridade de arquivos, hashes e preservação de evidências.

Este projeto foi desenvolvido para fins acadêmicos e educacionais.
