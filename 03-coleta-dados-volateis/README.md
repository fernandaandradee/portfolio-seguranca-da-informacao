Coleta de Dados Voláteis em Linux

Tipo: Projeto acadêmico — Auditoria Forense de Sistemas Digitais.

Objetivo

Praticar a coleta de informações temporárias de um sistema, seguindo princípios de preservação de evidências digitais e a ordem de volatilidade da RFC 3227.

Atividades realizadas

Verificação de rotas e conexões de rede.

Identificação de processos em execução.

Consulta de sessões de usuários.

Coleta de informações do sistema e arquivos temporários.

Registro dos resultados em arquivos de evidência.

Conhecimentos desenvolvidos

Linux, comandos Bash, análise de processos, redes e coleta forense.

Este projeto foi desenvolvido para fins acadêmicos e educacionais.
