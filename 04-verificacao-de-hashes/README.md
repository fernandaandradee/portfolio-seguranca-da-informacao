Verificação da Integridade de Arquivos com Hashes

Tipo: Projeto acadêmico — Criptografia e Auditoria Forense Digital.

Objetivo

Verificar a integridade de arquivos por meio da comparação de valores hash.

Atividades realizadas

Verificação de arquivos usando SHA-256 e MD5.

Comparação dos resultados com hashes previamente registrados.

Identificação de arquivos que apresentaram divergências.

Análise da importância dos hashes na preservação de evidências digitais.

Conhecimentos desenvolvidos

Criptografia, funções hash, integridade de dados e análise de evidências.

Este projeto foi desenvolvido para fins acadêmicos e educacionais.
